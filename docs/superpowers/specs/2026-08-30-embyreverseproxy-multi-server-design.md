# Emby 302 反向代理多服务器配置设计

## 目标

让 Emby 302 反向代理同时监听多个端口，并将每个监听端口映射到独立的 Emby 服务器地址；V2 与 V3 均支持，现有单服务器配置继续可用。

## 配置格式

新增 `servers` 多行文本字段，每行格式如下：

```text
http://emby-a:8096 => 0.0.0.0:8099
http://emby-b:8096 => 0.0.0.0:8100
```

左侧为 Emby 根地址，右侧为监听地址和端口。监听地址可省略，省略时使用 `0.0.0.0`。空行跳过；格式错误、地址无效或端口不在 1-65535 范围内的行记录警告并跳过。

## 兼容与运行

旧字段 `emby_host`、`host`、`port` 保留读取。保存旧配置时自动生成一行 `servers`，新配置优先使用 `servers`。每个有效配置创建一个 FastAPI 应用和 Uvicorn 线程；停止服务时统一停止并等待所有线程。

## 验证

增加解析函数自检，覆盖默认监听地址、显式端口、空行和非法行；运行 Python 编译检查，并验证 V2/V3 manifest 版本与源码版本一致。
